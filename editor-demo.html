Watermarked page

The mark behind this text is a <wui-watermark> whose host is height: 0. It contributes nothing to the column, so reflowOverflow() never sees it as a break candidate and the sheet stays exactly one page tall.

It has no light DOM at all, so the caret cannot land inside it and a stray Backspace cannot take the page with it; pointer-events: none lets clicks fall through to the text. Which leaves nothing to click when you want to change the mark — hence the chip in the corner above, the one piece of it that does take a press.

Select it and the panel offers a word mark, an image (with the same crop dialog images use), opacity, angle, size, and whether it starts a page. Switch to Flow and the mark still covers a sheet's worth of column — it is sized from --wui-page-h, which falls back to 296mm when nothing is paginating.
